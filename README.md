# OpenVB Website

The marketing and community website for the **OpenVB Foundation** — the home of Visual Basic .NET. Built with Astro and Tailwind CSS, deployed to Vercel.

## Tech Stack

| Tool | Version | Purpose |
|---|---|---|
| [Astro](https://astro.build) | ^6 | Static site framework |
| [Tailwind CSS](https://tailwindcss.com) | ^4 | Utility-first styling |
| [Geist](https://vercel.com/font) | variable | Sans + mono fonts |
| [Bun](https://bun.sh) | 1.3.11 | Package manager & runtime |
| [Vercel](https://vercel.com) | — | Hosting & deployment |

## Getting Started

**Prerequisites:** [Bun](https://bun.sh) and [Node.js](https://nodejs.org) (v20+).

```bash
# Install dependencies
bun install

# Start the dev server (http://localhost:4321)
bun dev

# Build for production
bun run build

# Preview the production build locally
bun run preview
```
